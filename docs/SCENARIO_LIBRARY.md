# 场景合成与团队经验库

本轮实现单团队闭环：录入经验 → 选择经验与医生风格 → Pi Agent 合成 → 保存场景 → 进入演练。首页会列出已保存场景，刷新或重启后仍可进入。

## 启动

按 README 启动前后端，并配置既有 `CUEX_S2_*` 或 `PRIME_MODELS_JSON`。合成调用真实 Pi Agent，复用演练医生的模型配置；即使演练引擎使用 `fake`，合成也不会回退到模拟结果。没有有效模型配置时，界面报告失败。

经验和场景默认写入仓库根目录 `.cuex-runtime/library/library.json`。可通过 `CUEX_LIBRARY_DIR` 指定仓库外的可写目录，例如 `/var/lib/cuex/library`。升级时保留并备份此目录。医生记忆仍使用 `CUEX_AGENTS_DIR`；生成场景有独立医生 ID。

沿用现有部署入口保护。Nginx 示例中的 Basic Auth 覆盖 `/api/`；不要去掉入口保护后把共享写入 API 直接公开。本版本没有单独的账号、团队权限或管理密钥，适用于受控团队演示。

## 使用

1. 首页点击「AI 自动合成新演练素材」。
2. 「录入经验」填写适用情境、应对经验，保存后选入本次练习；也可不选经验。
3. 选择医生风格与门诊时间，点击「生成演练场景」。
4. 成功保存后点击「进入这场演练」，进入已有的完整实时演练页。URL 保留 `scenarioId`，可再次打开同一场景。
5. 返回首页可找到保存的场景；经验可以再次选用于新的合成。

## 初版范围

- 使用现有 ANSHU 资料包，AI 编排关切顺序、医生偏好与开场、重练和结束台词。医疗事实与关切点沿用资料包，不生成新的临床证据。
- 团队经验是手动录入的沟通策略；没有自动访谈萃取、PDF 导入或跨药品资料库。
- 风格和时间是生成场景时的上下文，不是到时强制中断的计时器。
- 单个 Node 进程以原子文件替换保存数据；本轮提供新增和读取，不含编辑、删除或多进程共享写入。
- 生成最多并行两次，模型调用限时 45 秒。生成失败、无效输出或保存失败会显示错误，且不跳转演练。若保存成功后网络断开，可回首页查找已保存场景。
- 不把录入经验当成医疗事实。不要录入患者隐私、账号凭据或未经授权的内容；选中的经验会发送给已配置的模型服务。

## 接口

| 方法 | 路径 | 内容 |
| --- | --- | --- |
| GET / POST | `/api/experiences` | 列出 / 新增经验 |
| GET / POST | `/api/scenarios` | 列出 / 真实生成并保存场景 |
| GET | `/briefing?scenarioId=...` | 对应场景资料 |
| WebSocket | `/ws/session?scenarioId=...` | 绑定对应场景；`session.start.scenarioId` 须一致 |

每个连接使用自己的场景快照。模型、关切判断、ASR 纠正、医生台词、重练和结束记忆均使用该快照；不存在的场景明确报错，不回退到默认场景。

## 验证

`pnpm --filter @cuex/server test` 包含持久化、失败不保存、跨来源拒绝、场景绑定及重练测试。真实模型验证需要有效的现有模型配置；不能用替身测试宣称真实模型调用成功。
