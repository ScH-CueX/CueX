# CueX 45 秒影片字幕独立审查

审查日期：2026-11-01。范围仅为本轮新增旁白字幕及其对既有音画的影响。审查者未参与制作，依据 video-shotcraft 的 `final-review.md`、`aesthetic-rules.md` 和当前 `video/docs/cinematic-spec.md`。本报告不重做未变化的全片功能、市场文案或版权审查。

**最终结论：本轮字幕审查通过，无必须修复项。** 数据、SRT、最终 MP4 的六段字幕及显隐边界通过；44 px 衬线白字、轻描边、0.58 黑底符合用户选择。两版画面流及时间信息完全一致，各自音轨与字幕前交付版完全一致。下方保留预检记录，并单独列出最终产物证据。

## 验收基准

- 六段原有旁白字幕，保留衬线字体。
- 用户明确选择 44 px 字号；白字、轻描边/阴影、紧贴文字的半透明黑底（不透明度 0.58），底部留白 48 px，内边距 7 × 18 px。
- 参考：`assets/references/caption-style.png`。本轮的 44 px 字号按用户选择验收，覆盖审美准则 Q11 的通用 56 px 下限，不要求恢复大字幕。
- 数据：`assets/captions/cinematic45.json`；SRT：`assets/captions/AI+医疗健康-记性好了一点-视频.srt`；旁白依据：`assets/audio/narration/manifest.json` 和六个实际 WAV 文件。
- 组件：`video/src/cinema/NarrationCaptions.tsx`。以下帧号为 30 fps、从 0 开始；`to` 为不包含的结束边界。

## 预检记录（最终 MP4 完成前）

**C1 ✓ 六段完整，文字一致。** JSON、SRT、旁白清单的数量、顺序和 ID 均对应。`enter`、`brand` 将朗读用的 `Cue X` 规范为品牌写法 `CueX`；除此之外逐字相同，没有删句、补句或变更标点。

**C2 ✓ 时间边界一致，无重叠、无越片。** JSON 起点与旁白 `fromFrame` 以及影片 `CINEMA_VOICE` 的起点相同；SRT 是相同边界按毫秒四舍五入，最大量化误差不超过 0.334 ms。六段结束均为 `from + ceil(实际 WAV 秒数 × 30) + 6`，没有触及镜头截断上限。

**A1 ✓ 六个旁白源文件未变。** 独立计算实际 WAV 的 SHA-256，均同时等于旁白 manifest 与字幕 JSON 内的哈希；`ffprobe` 时长均等于 JSON 的 `audioSeconds`。这只证明源旁白未变，不代替最终混音音轨的比较。

**V1 ✓ 当前样式符合确认基准。** 源码使用 `FONT.serif`（`CueX Serif SC / Songti SC / serif`）、44 px、500 字重、近白色 `#F7F6F2`、0.6 px 深色描边、轻阴影与 0.58 黑底。背板按文字宽度伸缩，未变成贯穿全幅的解释条。工作台和影片都引用同一组件，工作台初始参数同为 44 / 48 / 0.58。

**Q1 ✓ 三张最新静帧中的字幕可读，无截字或越界。** 已实际查看 `video/out/stills/f0210.jpg`、`f0710.jpg`、`f0975.jpg`（均 1920 × 1080）。衬线笔画清楚、白字与背板有足够视觉分离。44 px 是本轮有意采用的小字幕规格，不以通用大字规则判失败。

**Q2 △ 预检时保留。** 三张静帧覆盖了较长句和界面密集位置，但不能代表剩余三段、每段出入边界以及运动中的遮挡情况。预检阶段未将尚未确认更新的同名 MP4 当作新成片证据；此项随后由 F1/F2 关闭。
